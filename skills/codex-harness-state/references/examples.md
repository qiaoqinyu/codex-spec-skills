# Examples

## Use This Skill

- "We have three active experiments and I keep forgetting which one changed the
  data pipeline versus the model."
- "Set up a handoff so tomorrow's session knows exactly where to resume."
- "Create a progress tracker and experiment board for a week-long refactor plus
  benchmark campaign."

## Do Not Use This Skill

- "Add the verified smoke command we just found into `specs/commands.md`."
- "Repair stale routing between `AGENTS.md` and `specs/*.md`."
- "We only need a one-line summary of today's bugfix."

## Boundary Reminder

- stable rules, commands, and repo truth belong in durable guidance docs
- mutable current status belongs in `.agents/state/*`
- experiment logs and result artifacts still belong in the repository's normal
  result directories
